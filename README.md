# Rosie

Анімована рожева сова для ChatGPT Work: великі бірюзові очі, фіолетовий бант і золота корона. Створена за чотирма референсними зображеннями за допомогою вбудованої генерації зображень.

![Анімації Rosie](previews/all-states.gif)

## Файли

- [spritesheet.png](spritesheet.png) — прозорий спрайт-лист v2, 1536 × 2288 пікселів: 9 анімацій і 16 напрямків погляду.
- [previews/](previews/) — GIF для кожної анімації, загальний GIF і MP4, перехід у стрибок, напрямки погляду та контрольні зображення.
- [source/](source/) — архів вихідних матеріалів і запис про створення пета.

## Вихідні матеріали

[Архів зображень і промптів](source/rosie-artwork-and-prompts.zip) містить оригінальні референси, основний образ, анімаційні смуги та їхні ревізії, фінальний спрайт-лист, звіти перевірок і скрипти обробки.

Фінальний спрайт-лист пройшов структурну перевірку, перевірку якості, незалежну перевірку напрямків погляду та перевірку Pets перед завантаженням. Стабільний ID Rosie й дані про створення збережені в [creation-record.json](source/creation-record.json).
